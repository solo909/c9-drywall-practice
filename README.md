# C-9 Drywall Practice Quiz Website

Static English-only practice site for California C-9 Drywall study.

## Current quiz setup

- English only
- List 1 and List 2 remain separate
- Level 1: standard question bank
- Level 2: harder versions with scenario-based wording and adjusted measurements/conditions
- Level 2 randomizes answer-choice order every quiz
- 20 random questions per quiz
- Practice mode: immediate right/wrong feedback
- Test mode: score at the end
- Score history saved in browser localStorage
- Score history records List, Level, mode, and percentage
- Missed-question review

## Question pools

- List 1 Level 1: 86 questions
- List 1 Level 2: 86 harder variants
- List 2 Level 1: 90 questions
- List 2 Level 2: 90 harder variants

## Files

- `index.html` — page structure
- `style.css` — design
- `questions.js` — English-only question banks
- `script.js` — quiz logic, randomization, feedback, and score history
- `README.md` — project notes

## GitHub Pages update

Upload/replace the five files above in the repository and commit the changes. GitHub Pages will publish the update automatically from the configured branch.

## Local use

Open `index.html` in a browser.
